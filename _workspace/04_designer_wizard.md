# 질문 마법사 설계 (004 US1, T017·T018)

## 레이아웃
```
┌ .refine-card (region, 입력창 바로 위, 본문 최대 폭) ─────────────┐
│ 질문 다듬기 결과                                        [✕ 닫기] │
│ ┌ 원문 ─────────────────┐ ┌ 개선안 (강조 테두리) ─────────────┐  │
│ │ 스캔 이탈 왜 많아?     │ │ 최근 7일 scan_start → scan_…      │  │
│ └───────────────────────┘ │ 변경: 기간을 정함(원문에 없음) …   │  │
│                           └──────────────────────────────────┘  │
│ [입력창에 넣기]            [원문으로 보내기] [개선안으로 보내기]  │
└─────────────────────────────────────────────────────────────────┘
┌ .chat-input  textarea ··········· [✦ 질문 다듬기] [보내기] ┐
```
- 768px 초과: 원문·개선안 두 열(`grid`, 1fr 1fr). 이하: 위아래로 쌓고 버튼도 줄바꿈(주 버튼이 맨 위 오른쪽 끝)
- 원문은 `--color-surface` 배경, 개선안은 `--color-bg` + 강조색 옅은 테두리. 변경 요약은 개선안 아래 보조 글자 한 줄

## 컴포넌트
| 컴포넌트 | 신규/재사용 | 이유 |
|---------|-----------|------|
| `RefineCard.tsx` | 신규 | 표현 전용. 데이터·기록은 `refine.ts` 훅(frontend-dev) |
| 다듬기 버튼 | Chat 안 | 보내기 왼쪽, 아이콘(인라인 SVG, `currentColor`) + 라벨. 375px에서는 라벨 숨기고 `aria-label`로 |
| `.btn`·`.btn.primary`·`.icon-btn` | 재사용 | 003 상호작용 네 상태 그대로 |

## 상태표
| 상태 | 표현 |
|------|------|
| idle | 버튼 활성(입력 있음·실행 중 아님) / 비활성(빈 입력·공백·실행 중) |
| refining | 버튼 이름은 그대로("질문 다듬기"), 아이콘 회전 + `aria-busy`, 버튼·입력창·보내기 잠금. 안내 줄 "질문을 다듬는 중입니다" |
| card | 카드 표시, 포커스는 "개선안으로 보내기"로. ESC·닫기 → 카드 닫고 포커스 입력창 |
| error | 카드 없음. `#chat-hint`에 오류 한 줄(경고), 원문 유지 |

## 토큰
기존 토큰만: `--color-surface`, `--color-accent`(옅게 섞은 테두리), `--radius-md/lg`, `--space-*`, `--duration-*`, `--tint`. 새 토큰 없음.
등장 애니메이션은 투명도·위치 `--duration-base`, 동작 줄이기에서 0ms.

## 접근성
- 카드 `role="region"` + `aria-labelledby`(제목), 열리면 주 버튼 포커스, ESC 닫기
- 포커스 순서: 닫기 → (원문·개선안 읽기) → 입력창에 넣기 → 원문으로 보내기 → 개선안으로 보내기. 시각 순서와 같음
- 진행 상태는 버튼 `aria-busy`와 안내 줄 `aria-live`

## 레퍼런스와 다른 점
ChatGPT에는 없는 기능. 입력창 위 떠 있는 카드지만 그림자 대신 테두리 한 줄(그림자는 Drawer 전용 규칙 유지).
