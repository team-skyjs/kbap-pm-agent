# 설정 화면 설계 (US-010)

## 레이아웃
채팅과 같은 셸·최대 폭. 상단 바 제목 "설정". 구역(접근 토큰·상태·FE 저장소·택사노미·Amplitude)은 `--space-6` 여백과 구분선 한 줄로만 나눈다. 구역 제목 옆에 상태 라벨.

## 상태 라벨 (색 + 글자)
| 구역 | 라벨 |
|------|------|
| FE 저장소 | 미등록 / 등록됨(`--color-ok`) / 오류(`--color-danger`) |
| 택사노미 | 없음 / 업로드됨 |
| Amplitude | 미연결 / 연결됨 |
마지막 동기화·연결 시각은 정의 목록(`dl.metric`)의 한 줄.

## 폼
입력은 1px 테두리 + `--radius-md`, 포커스 시 `--focus-ring`. 모든 입력에 `aria-label`. 파일 입력은 시각적으로 숨기고 라벨 버튼("JSON 파일 선택")으로 대체, 키보드 포커스는 버튼 윤곽선으로 표시. 결과 문구는 `role="status"`.

## 반응형
`.field-row`가 줄바꿈되어 375에서 입력·버튼이 세로로 쌓임. 긴 URL은 `overflow-wrap: anywhere`.
