# 제안 카드 설계 (US-009)

## 레이아웃
AI 답변 아래 같은 폭의 카드 하나. 머리(제안 번호·종류 | 상태 라벨) → 제목 → 접는 구역 넷(근거·제안·실행 단계·측정 방법, `<details>`) → 결정 줄(메모 입력 | 되돌리기·보류·채택, 오른쪽 정렬).

## 상태표
| 상태 | 표현 |
|------|------|
| 기본 | 제안 구역만 펼침 |
| 미결정 / 채택 / 보류 | 상태 라벨 글자 + 옅은 배경색(`--color-ok`·`--color-warn` 섞음), 카드 테두리도 같은 색으로 옅게 |
| 저장 중 | 결정 버튼 비활성 |
| 저장 실패 | 결정 줄 아래 오류 문구 |

## 근거·퍼널
- 근거 종류 라벨: 지표(`--chart-1`), 코드(`--chart-4`), 택사노미(`--chart-3`) 옅은 배경 + 글자
- 코드 근거: 파일:줄 · 함수를 mono 보조 줄로, 코드 조각은 `--color-surface` 블록
- 퍼널: 기존/신규 라벨, 신규 행은 옅은 경고 배경. 표는 가로 스크롤 영역(`tabIndex=0`, `aria-label`)

## 접근성
카드는 `<article aria-label="제안 N: 제목">`, 메모 입력 `aria-label`, 상태는 색 없이도 글자로 구분.

## 레퍼런스와 다른 점
ChatGPT에는 없는 구조화 카드. 테두리는 카드에만 1px로 두어 답변 본문과 구분한다.
