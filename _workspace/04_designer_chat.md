# 채팅 화면 설계 (US-004·005·007·008)

메시지 구분과 타이포는 `04_designer_messages.md`. 이 문서는 입력창과 화면 상태.

## 입력창
스크롤 영역 밖 하단 고정, 본문과 같은 최대 폭. `--radius-lg` 윤곽 하나, 포커스 시 `--color-accent` 테두리. 자동 높이(`field-sizing`, 미지원 시 스크립트), 최대 `--composer-max-lines`줄 뒤 내부 스크롤. Enter 전송, Shift+Enter 줄바꿈, 한글 조합 중 Enter 무시. 아래 안내 줄은 높이 예약(키 안내 / 실행 중 안내 / 오류 문구).

## 상태표 (`viewState()`)
| 상태 | 판정 | 표현 |
|------|------|------|
| 전송 직후 | running, 도구 없음 | 점 세 개(투명도 애니메이션, 동작 줄이기 시 정지) |
| 진행 | running, 도구 있음 | 접힌 한 줄 "Amplitude 조회 중… (이름)", 펼치면 도구별 ✓/✕와 결과 요약. `aria-live=polite` |
| 완료 | completed | 도구 행 "✓ 조회 N건" + 본문 + 제안 카드 |
| 부분 완료 | completed + 상한 사유 문구로 시작 | 사유 첫 문장을 옅은 경고 블록, 나머지 본문 |
| 오류 | failed | 오류 문구 + "다시 시도"(직전 질문을 입력창에 복원, 포커스) |
| 세션 만료 | 전송 401 | 상단 배너 + 입력값 유지. api.ts 이벤트 연결은 접근 제한 PR |

## 스크롤
맨 아래(40px 이내)를 보고 있을 때만 새 내용에 맞춰 내려감. 입력창은 스크롤 밖이라 상태 전환에 위치가 변하지 않음.
