# 앱 셸 설계 (US-002)

## 레이아웃
```
┌ .sidebar (--sidebar-w, surface) ┬ .main ─────────────────────────────┐
│ 브랜드 · [새 대화]               │ .topbar [≡] 화면 제목 ······ [서버: ok] │
│ 대화 목록 (스크롤)               │ .scroll (세로 스크롤만)               │
│                                 │   .thread (max --content-max-w 중앙) │
│ 설정 (하단 고정)                 │ .chat-input-wrap (하단 고정, 같은 폭)  │
└─────────────────────────────────┴────────────────────────────────────┘
```
화면 전체 높이 고정(`--viewport-h`), 본문만 `.scroll` 안에서 스크롤.

## 컴포넌트
| 컴포넌트 | 재사용/신규 | 이유 |
|---------|-----------|------|
| `Shell.tsx` `Topbar`, `ShellContext` | 신규 | 화면마다 제목이 달라 각 화면이 상단 바를 그림. 접기 동작과 상태 배지는 컨텍스트로 공유 |
| `App.tsx` | 재구성 | 사이드 패널·Drawer 상태 소유, 새 대화 버튼·설정 링크를 패널로 이동 |
| `HealthBadge` | 재사용 | App에서 한 번 조회해 컨텍스트로 전달(화면 전환마다 재조회 방지) |

## 상태표
| 상태 | 표현 |
|------|------|
| 데스크톱 펼침/접힘 | [≡]로 전환. 접힘은 패널 완전 숨김. `localStorage`에 기억 |
| 모바일 Drawer 닫힘/열림 | [≡]로 열기. 배경 탭·ESC·화면 이동 시 닫힘. 열린 동안 `body` 스크롤 잠금 |

## 토큰 사용
기존 토큰만. 새 토큰 없음.

## 반응형
- `>768px`: 패널은 흐름 안의 고정 폭
- `≤768px`: 패널은 `position: fixed` Drawer, `--shadow-sm`, 배경막. 상단 바 좌우 여백 `--space-4`

## 접근성
- [≡] 버튼 `aria-label`("사이드 패널 접기/펼치기", "메뉴 열기"), `aria-expanded`
- Drawer `role="dialog" aria-modal`, 열릴 때 첫 링크로 포커스. 포커스 가두기는 접근성 기준 스토리에서
- 사이드 패널은 `<nav aria-label="대화 목록">`

## 레퍼런스와 다른 점
- 접힘 상태에서 아이콘 바 없음(아이콘 세트가 없어 완전 숨김 + 상단 바 버튼만)
