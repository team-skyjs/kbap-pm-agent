# 차트 블록 형식 (모델 출력 ↔ 프론트 파서)

API 계약이 아니다. 에이전트 답변 `content`(마크다운) 안에 들어가는 관례다. API 응답 shape는 그대로이고, 이 형식이 틀려도 API는 정상이며 프론트가 원문으로 보여 준다. 기준은 이 파일 하나다. 시스템 프롬프트(`backend/app/agent.py`)의 예시와 프론트 파서 검사(`frontend/checks/check-f7.ts`)는 아래 예시를 글자 단위로 쓴다.

## 형식

언어 표시가 `chart`인 펜스 코드 블록 하나에 JSON 객체 하나를 담는다.

````markdown
```chart
{"type":"line","title":"최근 7일 스캔 시작 사용자 수","x":["10-09","10-10","10-11","10-12","10-13","10-14","10-15"],"series":[{"name":"scan_start","values":[312,298,341,355,330,362,371]}]}
```
````

| 필드 | 타입 | 규칙 |
|---|---|---|
| `type` | `"line"` \| `"bar"` | 필수 |
| `title` | string | 필수, 1~80자 |
| `x` | string[] | 필수, 1~366개 |
| `series` | object[] | 필수, 1~4개 |
| `series[].name` | string | 필수, 1~40자 |
| `series[].values` | (number \| null)[] | 필수, 길이가 `x`와 같다. `null`은 결측. 전부 `null`이면 오류 |

- 다른 키가 있으면 무시하지 않고 **형식 오류**로 본다. 모델 오타를 조용히 넘기지 않기 위해서다.
- 형식 오류(JSON 파싱 실패 포함)면 프론트는 차트 대신 같은 내용을 일반 코드 블록(언어 표시 `chart`)으로 보인다.
- 한 답변에 차트 블록이 여러 개 있어도 된다.

## 막대 예시

```chart
{"type":"bar","title":"국가별 스캔 완료율(%)","x":["KR","JP","US"],"series":[{"name":"완료율","values":[41.3,38.0,45.2]}]}
```

## 형식 오류 예시 (원문 코드 블록으로 보여야 한다)

```chart
{"type":"pie","title":"지원하지 않는 종류","x":["a"],"series":[{"name":"s","values":[1]}]}
```
